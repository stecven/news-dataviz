# 排版项目 · 本周进展报告

**项目**：新闻数据可视化 —— 把报纸数据版做成「可编辑」的信息图（PowerPoint 原生图表，可点开改数据）
**周期**：2026-11-05 ～ 2026-11-11
**技术栈**：Python 3.12 · python-pptx · Pillow · SQLite（无 LLM、无第三方依赖）

---

## 一、本周目标

从「手工复刻一张报纸版面」推进到「**输入一段新闻稿 + 数据库，自动排出一整版可编辑的报纸页**」。

## 二、本周做了什么（进展脉络）

按时间线分四个阶段：

**1. 搭起最小闭环（11-05 ~ 11-07）**
- 抓取报纸版面原图、把图上的数据点写进 SQLite 素材库（`fetch_assets.py` / `seed_chart_data.py`）
- 用 PIL 画图标（温度计、雪花、水滴、暖气片等，含淡化背景版）
- 用 python-pptx 复刻出第一张单页温度计信息图（`build_onepage.py`）
- 立起「数据 → 选型器 → 版面规格 → 渲染」的流水线骨架

**2. 让系统「会选图、会配色」（11-08 ~ 11-09）**
- **选型器**：根据数据语义自动选图形 —— 比较大小 → 温度计，占比构成 → 半圆图；无适用图形时显式降级为占位图（不假装成功）
- **素材库语义化**：给素材打语义/外观/季节/风格标签，建受控词表（同义词归一）、使用与反馈表
- **统一视觉语言**：单一色板 + 字号层级（标题:正文 ≈ 20:11 pt），三张图并排时配色、字号一致

**3. 排版引擎地基（11-11 前半）**
- **图框**：每张图包一个框，内容在框内居中，支持按框缩放
- **单卡片适配外部边界**：外部给格子尺寸、内部自动缩放（内容决定画布 → 外部定边界）
- **整版流式排版**：多张卡片按行排布，行距严格等于 gutter，装不下时报错而非静默越界

**4. 整版自动排版（11-11 后半，本周核心成果）**
- **自动化编排**：自动拆段、认标题与导语、把段落与数据组匹配、组流、整版输出
- **多栏图文混排**：文本可分栏、可跨栏，卡片可跨栏、可并排（2 栏版式）
- **插图配图**：从主题词表抽段落主题，自动配一张合适的图标插图；查不到素材不阻塞排版
- **主题词表反着建**：库里有什么素材才建什么主题词，保证抽到的词一定能查到图

## 三、目前达到的效果

**输入**：一段新闻稿 + 数据库（无需手写任何排版指令）

**输出**：一张 2 栏的整版报纸页（10 × 15 英寸），包含——
- 标题、导语、正文（自动分栏）
- 与正文匹配的数据图表（自动选型：温度计 / 半圆图）
- 与段落主题匹配的插图
- 可编辑的 PPTX + 预览 PNG

**能力清单**：
| 能力 | 说明 |
|---|---|
| 自动选型 | 按数据语义选图形，无适用图形时降级为带说明的占位图 |
| 自动排版 | 拆段、认标题导语、匹配数据、组流、多栏排布 |
| 自动配图 | 主题词表抽主题 → 配插图，查不到不阻塞 |
| 可编辑输出 | 原生 PPTX 图表，可点开改数据 |
| 视觉统一 | 单一色板 + 字号层级，多图并排风格一致 |
| 健壮性 | 装不下/匹配不到/查不到素材均显式降级或报错，不静默越界 |

**验证**：全量自动化测试 **676 个全部通过**（130 秒），覆盖选型、求解、渲染、排版、编排、配图各环节。
